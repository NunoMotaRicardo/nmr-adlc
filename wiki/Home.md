# nmr-adlc

Developer lifecycle plugin. Distributed via the [nmr-plugins](https://github.com/NunoMotaRicardo/nmr-plugins) marketplace.

## Skills
`brainstorm`, `research`, `pm`, `implement`, `pr-review`, `diagnose`, `prototype`, `setup`.

## Setup in a repo
Run the `setup` skill: it creates the repo's `.sdlc/` configuration, including where the technical specs (default `specs/`), planning docs (default `docs/`) and user docs (default `wiki/`, optionally mirrored to the GitHub wiki) live. In an existing repo it analyses the current folders and proposes how to adapt them. See the contract reference in `docs/sdlc-contract.md`.
